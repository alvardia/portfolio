Browser MP3 File Tagger (Personal, 2026)

A project dedicated to my Sony Walkman mp3 player.

These older devices oftentimes require specific file and data formats to display song and audio file information correctly. It can be tedious work to download a file tagging software and determine the correct preset values for your specific device, especially when documentation is not readily available. This simple website handles preset information for a Sony Walkman S-14 mp3 player (other models not tested) behind the scenes and makes it easy to tag mp3 files and add cover art, all in-browser. I find that projects are most rewarding when they tackle a real-life problem. This project has already paid off—I use it often to quickly save podcasts onto my mp3 player for later listening.

Classroom Communication Aide (Team, 2025)

A "Technology for Social Good" class group project.

This AAC-inspired web app aims to ensure that elementary-aged english language learners (ELLs) can comfortably have their basic needs met in class when language and lack of resources are serious barriers. Equipped with a student interface and a teacher interface, this web app can be used to send pre-selected or user-crafted messages privately from a student to a teacher, such as a request to use the bathroom. The web app also has a built-in translator, profile settings, google account authentication, and a teacher dashboard to enroll students and view requests. Inspired by my own negative experiences as a young ELL, I pitched this project idea to the class and it was selected as one of eight projects to be implemented. The design of this project was shaped by scholarly literature review, interviews with real ELL specialists and teachers, and many team sessions around a whiteboard.

WWU Accessibility Map (Team, 2026)

A group project developed as part of an "Accessible Design" course.

Worked with a group of three other students to make our own revamped version of Western Washington University's accessibility map. We identified pitfalls in the current website, including missing helpful information such as the locations of benches around campus. We conducted a literature review and applied the principles we learned in class to make a WCAG-compliant web app compatible with screen readers and backed by WAVE automated error checking. Utilized AI effectively (as endorsed by our professor) to develop a fully working prototype in a narrow timeframe.

HTML, CSS, JavaScript, SupaBase, Leaflet map, WAVE, Accessible Design, IRB Training and Certificate
